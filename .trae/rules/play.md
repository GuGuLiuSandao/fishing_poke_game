# Project Rules

## 1. Coding Standards (代码规范)
- **全中文注释**：所有代码注释必须严格使用**简体中文**。
- **覆盖公开接口**：所有 Public/Exported 的函数、类、结构体，**必须**包含文档注释（说明功能、参数、返回值）。
- **解释核心逻辑**：遇到复杂逻辑（如并发、算法、资源管理），必须解释**设计意图 (Why)** 和 **实现思路 (How)**，而不仅仅是翻译代码。
- **拒绝废话**：严禁对显而易见的语法进行注释（如 `i++ // i加1`）。

## 2. Game Design Constraints (游戏设计约束)
- **禁止参考德州扑克下注规则 (No Texas Hold'em Betting Rules)**:
  - **核心差异**: 本游戏（"钓鱼"）**没有**德州扑克的 `Call` (跟注) 和 `Raise` (加注) 机制。
  - **下注即反打**: 这里的 `Bet` (下注) 是一种强制性的“反打/开牌”行为。一旦有人下注，其他人只能选择 `Fold` (弃牌) 或 接受比牌（Showdown），不存在“跟注看下一张牌”或“加注反击”的流程。
  - **思维误区**: 严禁套用德州扑克的 Pot Odds (底池赔率)、Implied Odds (隐含赔率) 或多轮下注模型。
  - **AI 设计原则**: AI 决策应基于“单轮比大小 + 心理战（偷鸡/抓鸡）”的独立逻辑，而非生搬硬套德州扑克理论。
