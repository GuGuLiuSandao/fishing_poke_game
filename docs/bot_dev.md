# “钓鱼”BOT 开发文档 (基因进化版)

## 1. 目标与设计理念
本项目的目标是构建一个**可进化**的 BOT 系统。

> **⚠️ 核心设计约束**:
> **禁止参考德州扑克下注规则**。
> 1. **无跟注/加注 (No Call/Raise)**: 本游戏只有 **Bet (下注/反打)**、**Fold (弃牌)**、**Check (过牌)**。
> 2. **下注即反打**: 面对对手下注，不能“平跟”看牌。必须通过 **Bet** 进行“反打”来争取比牌权利（Showdown）。
> 3. **无底池赔率 (No Pot Odds)**: 严禁使用 Pot Odds 计算。因为赢家只能赢取与自己下注等额的筹码（1:1 赔率），底池中的“死钱”无法通过比例放大收益。AI 必须基于 **P(Win) > 50%** 的绝对胜率逻辑。

放弃传统的人工调参（如“激进”、“保守”等抽象概念），采用**直接策略阈值**作为基因参数。
通过**遗传算法 (Genetic Algorithm)** 让 BOT 在自我对战中进化，自动寻找最优的策略参数组合。

## 2. 基因参数定义 (Gene Definition)
每个 BOT 由一组基因（浮点数参数）控制，这些参数直接对应决策逻辑中的阈值或概率。
参数设计力求**可解释性**，让人类能直接看懂 BOT 的策略倾向。

### 2.1. 行动阈值类 (Action Thresholds)
*   **`open_bet_thresh` (主动下注门槛)**:
    *   范围: 0.0 ~ 1.0
    *   含义: 只有当牌力强度（胜率分位）高于此值时，才考虑主动下注。
    *   解释: 0.8 表示“只玩 Top 20% 的好牌”。
*   **`follow_bet_thresh` (反击下注门槛)**:
    *   范围: 0.0 ~ 1.0
    *   含义: 在后手位置时，牌力高于此值才会反击（下注）。通常比主动下注门槛更高。
*   **`defend_thresh` (防守/跟牌门槛)**:
    *   范围: 0.0 ~ 1.0
    *   含义: 牌力低于此值时，面对任何行动（甚至过牌）都倾向于弃牌（除非是免费 Check）。
    *   解释: 0.1 表示“Bottom 10% 的烂牌直接扔”。

### 2.2. 概率控制类 (Probability & Sizing)
*   **`bluff_rate` (诈唬率)**:
    *   范围: 0.0 ~ 0.5
    *   含义: 当牌力**不满足**下注条件时，有多大的概率强行下注（偷底池）。
*   **`bet_power` (下注尺度指数)**:
    *   范围: 1.0 ~ 5.0
    *   含义: 控制下注金额与牌力的关系曲线。
    *   公式: `Bet_Ratio = (Strength)^Power`
    *   解释:
        *   1.0: 线性关系，牌力 0.8 下注 80%。
        *   3.0: 指数关系，牌力 0.8 下注 0.8^3 = 51% (只有极强牌才下满池)。

## 3. 遗传算法流程 (GA Workflow)

1.  **初始化种群**: 随机生成 N 个 BOT，每个 BOT 携带随机基因。
2.  **模拟对战 (Evaluation)**:
    *   让种群内的 BOT 进行分组锦标赛或随机匹配对战 M 场。
    *   记录每个 BOT 的最终筹码量或净胜场次作为**适应度 (Fitness)**。
3.  **选择 (Selection)**:
    *   保留适应度最高的 K 个精英 (Elites)。
    *   淘汰适应度低的个体。
4.  **繁殖 (Reproduction)**:
    *   **交叉 (Crossover)**: 父母基因加权平均或随机交换，生成子代。
    *   **变异 (Mutation)**: 子代基因有小概率发生随机扰动。
5.  **迭代**: 重复步骤 2-4，直到达到预定代数或收敛。

## 4. 预期产出与分级
训练结束后，训练脚本 (`train_genetic.py`) 会自动对历史种群进行“名人堂大乱斗”，根据实战胜率将 BOT 划分为 5 个档位，并导出到 `bot_presets.py`：

*   **Lv5_Legend (传奇级)**: 种群中的最强王者，适应度最高。
*   **Lv4_Master (大师级)**: 顶尖梯队 (Top 20%)，实力强劲。
*   **Lv3_Experienced (老手级)**: 中坚力量 (Top 50%)，有一定的策略但存在漏洞。
*   **Lv2_Casual (休闲级)**: 能够理解规则，但策略较弱 (Top 80%)。
*   **Lv1_Rookie (新手级)**: 刚入门水平，基本随机乱打或过于胆小 (Bottom 10%)。

这些预设可以直接在代码中通过名称加载：
```python
bot = GeneBot(preset_name="Lv5_Legend")
```

## 5. 其他算法模型

除了基因进化 BOT，我们还实现了两种基于经典理论的 BOT，用于提供多样化的对手和基准测试。

### 5.1 MathSolver (数学家)
*   **核心逻辑**: 基于**期望值 (EV)** 和 **凯利公式 (Kelly Criterion)** 的严格数学推导。
*   **优势**: 决策在数学期望上永远为正，擅长在 1v1 长盘对局中稳定盈利。
*   **特性**:
    *   **天水规则适配**: 能够识别“天水”牌型（≥8点），在无人下注时 Check 引诱对手，有人下注时果断反击。
    *   **赔率计算**: 考虑了游戏特殊的 1:1 赔率上限（赢家只能赢取与自己下注等额的筹码），修正了 Pot Odds 计算。
    *   **弱点**: 在 6 人局中可能因为过于“理性”和规避高波动，而被乱打的对手通过高方差（Variance）击败。

### 5.2 CFR Bot (纳什均衡)
*   **核心逻辑**: 基于 **Counterfactual Regret Minimization (CFR)** 算法训练出的**纳什均衡 (Nash Equilibrium)** 策略。
*   **训练方式**: 通过 100,000+ 次自我博弈，最小化“后悔值”，生成不可被剥削的最优策略树。
*   **多人局适配 (Multiplayer Adaptation)**:
    *   CFR 原生基于 1v1 零和博弈训练。
    *   针对 6 人局的高底池赔率（Ante 1:6），引入了 **Rank Heuristic Adjustment**：将手牌强度映射放宽（Rank // 2），使 BOT 能够玩 Top 30-40% 的手牌，适应松凶（LAG）环境。
    *   **统一决策逻辑**: 统一了 Initial 和 Follow 阶段的牌力评估，防止出现“主动下注被反打后立刻弃牌”的逻辑断层。
