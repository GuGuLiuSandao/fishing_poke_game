# 项目文档索引

本文档是项目资料的统一入口。Agent 或开发者应先按任务类型读取对应权威文档，不要从代码注释推断产品规则。

## 产品

- [`product/vision.md`](product/vision.md)：当前产品形态、长期目标、范围与决策原则。产品范围或方向变化时更新。

## 玩法规则

- [`rules/game-rules.md`](rules/game-rules.md)：玩法规则的唯一权威来源。修改牌组、行动、下注、结算或胜负逻辑前必读。

## AI 与 Bot

- [`ai/bot.md`](ai/bot.md)：当前 Bot 阵容、信息边界、基础设施、评测标准和未来研究约束。修改 Bot、模拟器或训练逻辑前，与规则文档一起阅读。

## 开发

- [`development/godot.md`](development/godot.md)：Godot 客户端结构、启动方式和验证命令。
- [`development/ui-mvp.md`](development/ui-mvp.md)：MVP 界面方向、外部实现参考、素材来源和授权记录。

## 维护约定

- 新文档必须归入上述分类；出现稳定的新类别时，再新增目录并更新本索引。
- 同一事实只保留一个权威来源，其他文档使用链接引用，不复制长期易过期的内容。
- 已经移除的方案不在主线建立并行文档。
- 玩法规则变化先更新规则文档，再更新测试与实现。
- Bot 产品状态或验收标准变化同步更新 Bot 文档。
