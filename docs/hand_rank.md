# 牌型映射说明
# 牌型标识格式：
# - PAIR|SUB:x：对子，x 为对子内部等级，数值越大对子越强
# - POINT:p|WEIGHT:w：普通点数 p，w 为最大权重牌等级
# - SPECIAL_*：规则中独立列出的特殊牌型
# - SUPREME：最大牌型
# 对子子等级对应关系：
# - 100: Q 对，80: 2 对，60: 红 8 对，40: 红 4 对，20: 黑 10 对，1: 其余对子
# 最大权重等级对应关系：
# - 5: Q，4: 2，3: 红 8，2: 红 4，1: 黑 10，0: 无权重牌
# 牌力三元组含义：
# - 牌型等级：区分大类强度（普通点数 < 特殊牌型 < 对子 < 最大牌型）
# - 子等级：对子用子等级细分强度，其余类型为 0
# - 最大权重：普通点数牌型用于打破同点数的平局
