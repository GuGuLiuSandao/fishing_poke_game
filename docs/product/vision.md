# 产品方向

## 最终目标

将项目建设为一款完整的 Godot 本地单机游戏，并通过可复现的学习与训练，得到真正强力、能够与人类玩家稳定对局的 AI Bot。

“强力”不能只由直觉或单一脚本对手定义。未来选定训练路线时，需要建立隔离的训练、验证和最终测试数据，明确与基线 Bot、不同座位和人数配置以及人类玩家对局的评测方法。

## 当前产品形态

- Godot 4 本地单机版。
- 1 名真人玩家对战 1～5 个 Bot，默认 3 个 Bot。
- 当前正式对手只有 `LegacyGeneBot`，用于形成可玩的产品基线。
- 当前游戏运行时不训练，不提供 Bot 难度或算法选择。

## 当前范围

- 维护准确、可测试的规则层和完整单机对局体验。
- 保留统一 Bot 契约、隐藏信息边界、纯模拟器、固定随机种子和可复现评测能力。
- 在技术路线确定前，以稳定基线和评测基础设施支撑后续 AI 研究。

以下内容不属于当前主线：

- Python 服务端与 WebSocket 大厅；
- Web、Legacy Web 和 Standalone 客户端；
- 真人联网对战；
- 未经确认的搜索、CFR、自我对战或机器学习实现。

## 决策原则

1. 玩法以规则文档为准，不为适配某种 AI 隐式改变规则。
2. Bot 只能使用被契约允许的信息，规则层必须复核其动作。
3. 新 AI 路线开始实现前，先明确数据来源、训练方式、目标指标、资源预算和验收门槛。
4. 实验结果必须可复现，并与训练数据和调参过程隔离。
5. 被替代的实现不在主线并行维护。
