“钓鱼”图形界面与联机产品开发文档

1. 图形界面目标

提供沉浸式、直观的牌桌体验。

- **核心 UI 特性**：
  - **真实扑克牌展示**：采用 `deckofcardsapi.com` 提供的真实扑克牌图片。
  - **沉浸式搓牌模式 (Squeeze Mode)**：
    - 可通过左上角设置开启。
    - 开启后，发牌时仅显示第一张，第二张可通过点击“眼睛”按钮进入搓牌界面。
    - 支持拖拽搓牌和拇指遮挡模拟。
  - **动态座位布局**：根据玩家人数（2-6人）自动调整座位位置。
  - **历史记录 (History)**：
    - 每个人物头像旁显示最近一次行动气泡。
    - 下拉式菜单查看个人详细行动历史。
    - 全局对局记录弹窗 (Log)。
  - **智能操作按钮**：
    - 仅在轮到自己时显示可用按钮。
    - "下注" (Bet) 在跟注阶段自动变为 "带" (Dai/Call/Bet Pot)。
    - 增加 "下一局" (Ready) 按钮，支持全员弃牌或结算后快速开始。

支持桌面与移动端的基础适配（Tailwind CSS 响应式）。

2. 联机功能

- **WebSocket 实时同步**：
  - 游戏状态（Pot, Round, Turn）实时广播。
  - 玩家动作（Bet, Fold, Check）即时反馈。
  - 断线重连支持（基础）。

3. 账户与数据

- 账号体系：目前为临时 Session ID 或简单的 Name 输入。
- 数据记录：单局内的筹码变化实时显示。

4. 技术实现方向

- **前端**：React + Tailwind CSS (单文件 index.html 集成)。
- **后端**：Python (FastAPI + WebSocket) + 多线程游戏循环。
- **通信**：JSON 消息协议。

5. 版本路线

- **当前版本**：
  - 完整 6 人局支持。
  - 核心玩法（发牌、比牌、底池逻辑）完备。
  - UI 美化（玻璃拟态、动画效果）。
  - 搓牌与历史记录增强体验。

- **未来迭代**：
  - 账号持久化。
  - 战绩回放。
  - 更多动画特效（筹码飞入等）。
